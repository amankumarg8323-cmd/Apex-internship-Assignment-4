
# Apex Lark AI & Machine Learning Internship – Day 4

## 📌 Topic
**Feature Engineering & Data Transformation**

## 📖 Project Overview
This project is part of the Apex Lark AI & Machine Learning Internship Program. The objective of this project is to perform feature engineering and data transformation techniques to prepare a real-world dataset for Machine Learning.

The project uses a Telecom Customer Churn dataset to analyze customer information and transform raw data into a machine-learning-ready format.

---

## 🎯 Objectives

- Analyze the dataset and identify numerical and categorical features.
- Check and handle missing values.
- Create meaningful new features from existing data.
- Convert categorical data into numerical format.
- Apply data scaling and normalization techniques.
